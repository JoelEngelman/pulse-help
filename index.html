Messaging

Get your conversations moving.

Sending a message

Open a conversation, choose the account you want to message, type your message and send it. The recipient needs a Pulse account.

Messages not appearing?

Check that you're signed into the expected account, refresh Pulse, and verify that the recipient account exists.

Two-way messaging

Pulse conversations are designed to work in both directions. If messages only appear on one side, check the connection and account session first.

Troubleshooting

Try these quick checks before anything complicated.

Pulse won't load

Refresh the page, check your connection, then try opening Pulse again. If you're on a managed network, a network policy may be involved.

Database or account error

If account creation reports a database error, don't repeatedly create accounts. Refresh and try again. Persistent errors should be reported to Pulse support.

Messages aren't sending

Make sure both accounts exist, you're using the correct account, and the network connection is working.

School & restricted networks

Pulse is designed with compatibility in mind, but managed networks can still apply their own rules.

NETWORK GUIDE

When a school network gets in the way.

Some schools and organisations restrict particular domains, ports or services. Pulse uses web-friendly HTTPS endpoints and a proxy architecture where supported.

Privacy & safety

Keep your account under your control.

Protect your password

Use a password you don't share with anyone else. Avoid reusing an important password from another service.

Use the right account

Before sending something private, check the account name and conversation you're using.

Report a problem

If something looks wrong, capture the error message and report it without sharing your password or private credentials.
